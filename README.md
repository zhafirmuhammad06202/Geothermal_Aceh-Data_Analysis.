Geospatial & Geochemical Analysis of Geothermal Potential in Aceh, Indonesia

Project Overview
Proyek ini merupakan studi kelayakan teknis menggunakan metode Exploratory Data Analysis (EDA) untuk memetakan dan mengevaluasi potensi energi panas bumi di wilayah Aceh. Fokus utama proyek ini adalah mengidentifikasi lokasi yang memiliki efisiensi operasional tinggi (risiko korosi rendah) guna mendukung kemandirian energi di wilayah terpencil.

Tech Stack & Skills
Programming: Python (Pandas, Numpy)
Data Visualization: Plotly Express (Interactive Charts), Folium (Geospatial Mapping)
Geophysics Knowledge: Geothermometry, Fluid Chemistry (pH & Silica analysis), Regional Geology.

Key Contributions (Action)
Geospatial Mapping: Memetakan titik manifestasi panas bumi (Jaboi, Seulawah, Ie Seu-um, dll) menggunakan koordinat geografis ke dalam peta satelit interaktif untuk analisis sebaran spasial.
Geochemical Correlation: Melakukan analisis multivariat untuk membuktikan hubungan antara kadar Silica (ppm) dengan Temperatur Permukaan, guna mengestimasi kualitas reservoir bawah permukaan.
Technical Risk Assessment: Mengevaluasi tingkat keasaman (pH) di setiap lokasi untuk menentukan risiko korosi pada infrastruktur pembangkit listrik.
Comparative Study: Menganalisis kondisi vegetasi dan aksesibilitas wilayah menggunakan Satellite Imagery untuk menilai tantangan logistik di lapangan.

Results & Insights
Optimal Site Selection: Mengidentifikasi Ie Seu-um sebagai lokasi paling strategis untuk pengembangan energi jangka pendek karena memiliki pH netral (7.5) yang meminimalisir biaya perawatan pipa, dibandingkan Seulawah Agam (pH 2.5).

Energy Sovereignty Vision: Menyusun rekomendasi pemanfaatan energi panas bumi skala kecil untuk wilayah pelosok seperti Pulo Aceh, guna menciptakan kemandirian listrik bagi komunitas nelayan lokal.
Interactive Dashboard: Menghasilkan file peta interaktif (.html) yang memungkinkan pemangku kepentingan melakukan inspeksi data secara mandiri.
